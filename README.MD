# ESEP Grade Calculator

This library is a simple utility to calculate your grades.

The project requires Go 1.24.4 or later. The Go module and source files are located in the `grade-calculator` directory.

Run unit tests from the repository’s main folder:

```sh
cd grade-calculator
go test ./...
```

Run unit tests with code coverage from the same `grade-calculator` directory:

```sh
go test -cover ./...
```
